# 跳棋程序 产品需求文档（PRD）

- 版本：v1.0（MVP）
- 负责人：PM
- 关联任务：`5523825a-d074-464c-811b-c93cd7a1736a` —「我需要编写一个跳棋程序，请产品经理安排设计并实现」
- 状态：需求冻结，进入实现验收

## 1. 背景与目标

用户希望拥有一款可直接运行的「跳棋」程序。中文语境下「跳棋」默认指**中国跳棋（Chinese Checkers，六角星棋盘）**，而非国际跳棋（Draughts，吃子棋）。MVP 目标是交付一个**零依赖、开箱即玩**的终端跳棋程序：既能人人对战，也能与简单 AI 对战，规则正确、可自动化验证。

## 2. 目标用户与核心场景

| 用户 | 场景 | 诉求 |
|---|---|---|
| 普通玩家 | 双人同屏轮流走子 | 看得到棋盘、知道自己能走哪里、操作简单 |
| 单人玩家 | 人机对战 | AI 有基本走子策略，能下完整局 |
| 演示/验收者 | 无交互跑一局 | 一条命令自动对弈，证明规则引擎可完整运行 |

## 3. 范围

### 3.1 MVP 包含

- 标准六角星棋盘：121 个棋位，6 个营地各 10 孔。
- 2 人对战：红方 R 先手、蓝方 B 后手，各 10 枚棋子。
- 规则：单步移动到相邻空位；跨过任意颜色的一枚棋子落到紧邻空位；支持连续跳跃，可在任意一跳后停下；**跳跃不吃子**。
- 胜负：一方 10 枚棋子全部进入对方营地即获胜。
- 交互：终端棋盘渲染、坐标输入、`help` / `moves <坐标>` / `quit` 命令。
- 模式：人机对战（玩家执红）、双人同屏、AI 自动演示。
- 非交互参数：`--demo`、`--seed N`、`--max-plies N`、`--ai-vs-ai`。
- 自动化测试：规则引擎与 AI 的单元测试。

### 3.2 MVP 不包含（后续迭代）

- 3/4/6 人多方对战（棋盘数据模型已预留六向对称结构）。
- 图形界面、联网对战。
- 存档 / 悔棋 / 计时 / 棋谱导出。
- 强 AI（α-β、MCTS）与难度分级。

## 4. 功能需求

| 编号 | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| FR-1 | 生成标准 121 孔六角星棋盘，6 个营地各 10 孔且互不重叠 | P0 | 单元测试断言计数与互斥 |
| FR-2 | 初始局面红方占上营、蓝方占下营，各 10 子，红先 | P0 | 单元测试 + 开局渲染 |
| FR-3 | 合法着法仅含：相邻空位单步、跨一子落空位的跳跃、可停止的连跳 | P0 | 单元测试覆盖正反例 |
| FR-4 | 跳跃不吃子，连跳不得两次落到同一棋位 | P0 | 单元测试 |
| FR-5 | 非法输入（坐标非法、无己方棋子、目标占用、不可达）被拒绝且不改变局面 | P0 | 单元测试 + 手工验证 |
| FR-6 | 任一方占满对方营地全部 10 孔即获胜 | P0 | 单元测试 |
| FR-7 | 终端渲染包含行列标尺、双方棋子、当前回合与进营数 | P1 | 人工检查渲染截图/输出 |
| FR-8 | 支持人机、双人、AI 自动演示三种模式 | P1 | 启动各模式验证 |
| FR-9 | AI 在合理时间内给出合法着法；无可走时返回 None | P1 | 单元测试 + 自动对局 |
| FR-10 | `python3 -m checkers --demo` 能自动完成整局且不崩溃 | P0 | CI 式命令行验证 |

## 5. 非功能需求

- **零第三方依赖**：仅 Python 3.10+ 标准库，降低运行门槛。
- **规则层与 I/O 解耦**：`board` / `game` 不依赖终端，便于测试与未来替换 UI/AI。
- **可测试性**：核心规则覆盖率以关键不变量为主，全部单测可通过一条命令运行。
- **健壮性**：自动对局设置步数上限，防止异常局面死循环。
- **性能**：单回合合法着法为数百量级，终端与贪心 AI 即时响应。

## 6. 约束与假设

- 采用中国跳棋规则，语义上与「国际跳棋（吃子）」区分。
- MVP 先做 2 人；棋盘坐标与营地数据按六向对称设计，后续可扩展到 3/4/6 人。
- 运行环境为本地终端，无网络、无图形库依赖。

## 8. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 「跳棋」棋种理解偏差 | 交付物不符合预期 | PRD 明确为中国跳棋；如需国际跳棋另立需求 |
| 贪心 AI 在残局可能长时间不结束 | 演示体验差 | 设置 `--max-plies` 上限；演示验收固定种子 |
| 多角色并行改动导致代码分叉 | 集成成本 | 以 developer 工作区代码为唯一实现基线，designer 参考实现只读 |
