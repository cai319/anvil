# Anvil v1.42.0 — 切片上下文隔离、独立派遣任务与自动回切

> 发布日期：2026-11-10
> 版本：1.42.0

## 1. 切片上下文

- 角色上下文从 `(role, task)` 扩展为 `(role, task, slice)`：
  - task 级：`task_id`
  - 切片级：`task_id::slice::<slice_key>`
  - 全局：`__global__`
- 静态 `slices` 与运行期 `plan_slices` 都写 `slice_key`；静态切片不写
  `source_step_id`。
- 同一 slice 的 scope/execute/verify/fix/verify2/decide 共享会话；不同 slice
  的原始对话隔离。
- CIC、step/reply prompt、agent inbox、知识快照都按当前 slice + task-wide 过滤。
- task reset/delete 清全部 slice；run/slice reset 只清当前 context；workspace/cwd
  仍按 task 复用。
- workflow 重启/新 execution 清旧 slice 槽，避免 resume 上一次执行的对话。

## 2. 独立派遣任务

- 新增 `POST /tasks/{id}/dispatches` 与 `GET /tasks/{id}/dispatches`。
- 新增 `anvil task dispatch`。
- 派遣任务是一张**独立顶层任务卡**：
  - `type=dispatched`
  - 无 `parent_id/parent_step_id`
  - 不阻塞来源 workflow
  - 只保留 `source_task_id/source_slice_key/requested_by` 软关联
- 请求哈希去重、派遣深度限制、目标角色忙时排队。
- 与历史“委派子任务”区分：委派仍是阻塞式步骤拆工，派遣是独立工作。

## 3. 上下文路由

- 新增 `services/context_router.py`：
  - 同 task 同 slice → 复用当前上下文；
  - 同 task 已知 slice → 切回该 slice 槽；
  - 弱相关/无归属 → 独立派遣任务；
  - 身份硬规则优先，歧义时用轻量词法相关度；
  - 决策写 `context.routing` audit。
- `anvil task mention` 默认走自动路由，可用 `--slice/--context-mode` 覆盖。
- findings 复评强制 task-level，不会 resume 切片 step run。

## 4. 自动回切

- 新增 `task_dispatches` 状态机：
  `open → return_ready → returning → returned`；
  失败/终止：`no_return/cancelled`。
- 派遣任务 `done` 后，若原 run 仍 `suspended`、原 step 仍 `running`、原 task
  未终止：写 `runs.wake_note` 并由 scheduler 自动 resume 一次。
- 跨切片临时复核使用 `runs.context_return_*`，结束/失败后回切一次。
- wake_note 支持追加合并；只有 daemon 真正写入 stdin 后清空。
- 同一 return run 的多个派遣结果合并为一次回切。
- one-shot run 无 `rs:` 常驻会话时不自动回切，避免丢失上下文。

## 5. 角色状态机联动

- `_nudge_stalled` 识别派遣/临时切片/角色他处执行，不再提前拉回原切片。
- 超时、崩溃、run reset、self reset 只清当前 slice；task 删除才清全部 slice。
- `role_inbox_cursors` 主键改为 `(role_slug, task_id, slice_key)`；
  `anvil inbox check/commit` 支持 `--slice/--task-wide`。
- 队列优先级接线：return=10 / step=20 / findings=40 / mention=50 / default=100。
- `_clear_terminal_role_runs` 同步清理 `current_context_key/current_slice_key`。
- 角色运行时 API/UI 按 task+slice 展示上下文。

## 6. 数据与迁移

- `runs`：`slice_key/wake_note/dispatch_id/origin/context_return_*`
- `tasks`：`source_task_id/source_slice_key/source_step_id/source_workflow_id/
  requested_by/dispatch_status/dispatch_reason/dispatch_reason_json`
- `role_task_sessions`：`task_id/slice_key`
- `role_sessions`：`current_context_key/current_slice_key`
- `notes`：`slice_key`
- `context_manifests`：`slice_key`
- 新表：`task_dispatches`
- `schema.slice_context_v2` 补齐旧库的 notes/manifest 列，并迁移 inbox cursor。
