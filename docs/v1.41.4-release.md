# Anvil v1.41.4 — Tracker 字段 LLM 精简与可配置上限

> 发布日期：2026-11-05
> 版本：1.41.4

## 1. 外部字段长度控制

问题板提交到问题跟踪服务器前：

- `description_md` 保持完整，不限长度；
- 其余字段超过配置上限时，调用默认 CLI 运行时做一次 LLM 精简；
- LLM 返回后再次硬校验，超过上限则本地截断兜底；
- LLM 不可用、超时或返回非法 JSON 时直接截断，不阻断提交；
- 枚举/优先级字段不交给 LLM 改写，但仍参与最终长度校验。

默认上限 **512 字符**，可在「工具」页「问题跟踪服务器」→「单字段最大字符数」
配置（范围 64–4096），保存后持久化到 `settings`，后续提交立即生效。

环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `ANVIL_ISSUE_TRACKER_FIELD_MAX_CHARS` | 512 | 字段上限的环境默认值；工具页保存值优先 |
| `ANVIL_ISSUE_TRACKER_COMPACT_TIMEOUT` | 60 | LLM 字段精简超时（秒） |

## 2. 工具页

- 新增「单字段最大字符数」输入框，与服务器地址一起保存；
- 修复「未配置」徽章被挤压后竖排换行、纸色背景对比度不足的问题：
  - 禁止 flex 收缩和换行；
  - 未配置状态使用纸面色背景 + 深色边框/文字；

## 3. 日志

- LLM 失败/截断：`tracker compact ... fallback=truncate`、`tracker fields truncated...`；
- 不记录字段正文。
