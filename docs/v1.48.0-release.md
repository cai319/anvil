# Anvil v1.48.0 — 状态单写者、结构拆分与 OpenAPI 契约

> 版本：1.48.0（P0 状态收敛、P1 结构/契约、P2.15 Raft 借鉴）
> 日期：2026-11-22

## 亮点

- **状态收敛**：任务状态、dispatch 状态、角色状态、事件账本与子任务视图各自收敛到单写者或单投影。
- **结构拆分**：`workflow.py` 与 `daemon.py` 拆为职责模块；scheduler 22 个阶段收敛为 10 个域。
- **契约生成**：OpenAPI 从 32 个 schema 扩到 92 个；前端核心实体改用生成类型。
- **上下文经济**：CIC 冷唤醒预算可配，并向角色注入拉模式未读提示。

## P0 状态与所有权

- `tasks.status` 唯一写者：`services.tasks.transition_task`（CAS）；claim/unclaim/submit/
  review/cancel/reopen、workflow、governance、board、findings 全部迁移。
- `tasks.dispatch_status` 改为派生视图（以 `task_dispatches.status` 为权威），删除双写。
- 任务内角色状态由 `services.role_state` 服务端推导；新增单任务与批量端点
  `GET /tasks/{tid}/role-states`、`GET /tasks/role-states?task_ids=...`。
- 委派/派遣统一投影：`GET /tasks/{tid}/children`，`relation_type` 区分行为差异，
  UI 共用子任务卡片。
- 事件/活动/审计单写者：`services.ledger.emit_activity/emit_audit`；54 处直写迁移；
  静态守卫禁止 `ledger.py` 之外直写 `activities/audit/events`。
- 新增加 `services/work_items.py` 与 `GET /work-items`，统一读取
  wake/reminder/action_card/board_draft。
- 删除 `cost_ledger`、`repo_split_map` 建表与迁移写入；旧库保留但不再读写。
- 新增 `dev/architecture-guardrails.md`：单写者规则、禁止事项、复杂度预算。

## P1 结构与契约

- `workflow.py` 4,505 → 75 行门面；拆为 common/definition/revision/execution/review
  五个模块（最大 1,618 行）。
- `daemon.py` 3,036 → 160 行核心 + mixin；拆为 common/runtime_process/delivery_queue/
  context_engine/subagent_tracker（最大 1,108 行）。
- Prompt 单点化：`_run_prompt_kind` / `_protocols_for_run` 唯一分类；
  16 个协议块 SHA-256 快照 + `step_prompt` 金样测试。
- Scheduler：22 阶段 → 10 个域入口，顺序与逐阶段异常隔离保持不变，测试锁定。
- 前端：TaskDetail 2,834 → 1,831 行，抽出 7 个组件；`statusVocabulary.ts` 统一
  task/run/dispatch 词表，回放短标签也并入。
- OpenAPI：`schema.d.ts` 生成链路（`backend/dump_openapi.py` + `npm run gen:api`）；
  Task/Run/Workflow/Finding/知识卡/时间线/租约/运行时/指标/图/子代理等改用生成类型；
  `client.ts` 约 2,400 → 1,857 行。

## P2.15 Raft 借鉴

- Pull inbox 与 held draft 原已具备（`anvil inbox check/commit`；
  `expect_activity_id` 409 held + `force`）。
- 新增 `ANVIL_CIC_COLD_BUDGET_CHARS`（默认 32000 字符），并写入
  `context_manifests.budget_chars`。
- 冷唤醒 CIC 注入「未读消息（拉模式）」块：未读数 + 拉取/确认指令。
- P2.16–P2.18（DeepSeek Mandate、OpenAI OS 沙箱）按 owner 决定不实施。

## 修复

- `RunStatus` 枚举补齐 `suspended`。
- `ContextManifestBlock.source_ids` 兼容整数活动 id，修复
  `GET /runs/{rid}/context-manifest` 的 500。
- `test_advance_is_serialized` 改为每线程独立连接，消除全量偶发失败。
- 任务删除 tombstone 不再把已删除 `task_id` 写回 events。

## 行为变化与升级注意

- **需重启** 才能加载后端改动。
- 响应契约更稳定：部分可选字段缺省时返回 `null`（如 `pending_revision`、`dispatch`）。
- `activities` / `audit` 现在同步写入 `events` 账本；events 表增长会更快，
  建议后续观察并制定保留/归档策略。
- 冷唤醒 CIC 多一个未读拉取提示块；默认总预算仍为 32000 字符。
- 委派/派遣子任务卡片与状态文案统一，属可见变化，语义不变。
- **无 CLI 功能变更**；`anvil --version` 输出 1.48.0。
