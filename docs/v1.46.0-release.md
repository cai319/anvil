# Anvil v1.46.0 — 知识入库必须条款、智能补全与任务完成自动收割

> 发布日期：2026-11-21
> 版本：1.46.0（知识质量门、补全队列与任务完成收割）

## 1. 知识入库必须条款

- 共享经验、角色知识、任务知识、频道/主题知识统一执行“提交前必须完整”：
  - 标题 ≤80 字、TLDR ≤200 字、正文 ≤4000 字、单字段 ≤2000 字；
  - 通用质量字段 `use_when / expected_effect / evidence` 必填；
  - 按 kind 校验类型必填字段；`exclusions` 与 `counterexamples` 作为同义别名统一；
  - 不满足时服务端返回 **422（知识格式不合法）**，不再生成半成品知识。
- 共享经验详情展示完整字段、正文、来源/标签/命中信息；审批前必须通过质量门。
- 收件箱经验条目标题不再截断，条目紧凑展示；未达入库标准时批准按钮灰化并显示原因。

## 2. 共享经验与角色知识智能补全

- 新增补全任务表 `knowledge_completion_jobs`，跟踪目标、归属角色、run/wake 与状态。
- 共享经验由收割角色（`source_role`）使用来源任务上下文补全；角色知识由归属角色用
  自身上下文补全；角色忙碌时排队，不抢占当前工作。
- 补全同时优化标题/TLDR/正文/字段长度并满足必须条款；补全完成后目标重新按质量门校验。
- 看板/详情显示 `补全排队中 / 补全处理中 / 补全完成 / 补全失败`；处理中或已达标时
  补全按钮灰化，失败/完成但未达标时允许再次补全。
- 历史已批准、已满足质量门但没有补全任务记录的条目，按 `补全完成` 展示
  （响应带 `inferred=true`，不伪造 job/run）；待审条目仍显示 `可入库`。
- 新增 CLI：`anvil lesson fill`、`anvil knowledge fill`；补全只允许收割角色/human 执行。

## 3. 任务完成后的知识收割提醒

- 顶层任务在 **Cindy 规划完成且 human 批准 workflow 落板**时，自动创建一条归属 Cindy 的
  `when(task:<id>:done)` 提醒；仅创建任务、尚未落板时不创建。
- 任务 `done` 时由现有 reminder 调度创建无任务 run，Cindy 用任务上下文收割：
  - 任务知识：`anvil task knowledge-write`（Cindy 只能写 `proposed`，参与者/human 批准）；
  - 主题知识：`anvil knowledge card-create` 写 proposed；
  - 频道知识：`anvil workspace knowledge harvest/propose`。
- Prompt 要求先读任务/步骤/run 证据、先查重、每条卡带完整字段，禁止 approve，不编造；
  没有可复用知识时明确输出“无新增”。
- 取消/删除任务会删除自动提醒；重新打开已落板任务会补回；启动回填只为已落板的活动顶层
  任务补提醒，历史 `done` 不追溯，孤儿提醒会清理。
- 新增功能开关 `knowledge_harvest_reminder`（默认开启），可在「工具」页关闭。
- 为避免“知识收割者不是任务参与者”导致 403：Cindy 对非参与任务只能创建 **proposed**
  任务知识，不能直接创建 active。

## 4. 知识库/收件箱 UI

- 共享经验与角色知识详情改为统一知识卡详情弹窗：约 50% 屏宽、80% 屏高，固定头部/
  底部、正文滚动，展示字段、质量门、补全状态与来源。
- 角色知识子页面：补全状态标记贴标题末尾；操作按钮固定在行尾；新增删除（文件和索引）；
  首次进入即显示角色知识数量。
- 共享经验列表修复行溢出遮挡时间戳/删除按钮；标签改为收件箱式紧凑 chip；行元信息
  （标签/repo/命中）上下居中对齐。
- 删除确认弹窗固定 560px 紧凑布局，标题/说明/按钮不再挤压。

## 5. 弹窗上下栏冻结

- 长表单弹窗统一迁移到 `.modal-flex`：弹窗本身不滚动，头部/底部 `position: relative`
  固定，仅 `.modal-flex-body` 滚动，并设置 `overscroll-behavior: contain`。
- 覆盖新建任务/频道、新建角色、运行时 YAML、知识提议/编辑器/清洗、工作流模板导入/
  版本/套用、流程强度、Token 清零、Gate 审核等；滚动时上下栏坐标不再移动，也不会从
  padding 缝隙露出正文。
- 知识详情、Finding 抽屉等已有独立滚动体保持原有冻结结构。
