## 2. Tracker 出站代理修复

问题现象：

- 测试环境 tracker 测试/提交超时；
- Wireshark 在物理网卡抓不到 Anvil 发出的报文；
- curl 从同一机器可以直连成功。

根因：

- `httpx` 默认 `trust_env=True` 会通过 `urllib.getproxies()` 读取 Windows 注册表 /
  macOS 系统设置里的系统代理；
- 系统代理常指向 `127.0.0.1:7890` 之类的本地地址，于是请求被 localhost 代理接管；
- curl 只读取环境变量，因此 curl 与 Anvil 行为不一致。

修复：

- tracker 出站固定直连：`trust_env=False` 且 `proxy=None`；
- 不读取 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`；
- 不读取 Windows 注册表 / macOS 系统设置里的系统代理；
- 由本机路由表直接选择出口网卡；
- 日志同时记录 `env_proxies` / `system_proxies`（仅诊断）、`proxy=none`，
  便于确认代理是否被绕过。
