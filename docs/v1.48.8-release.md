# Anvil v1.48.8 — 工作流模板删除与工作流页刷新修复

> 版本：1.48.8（新增工作流模板删除；修复任务详情工作流页刷新）

## 新增：工作流模板删除

- 新增 `DELETE /workflow-templates/{tid}`（human-only，成功返回 204）：
  - 永久删除模板及其全部版本（草稿/已发布）；
  - 写入 `template.delete` 审计，记录名称、来源、发布版本与被引用次数；
  - 模板不存在返回 404。
- 删除保护：
  - 仍被运行中 workflow（`running`）引用时返回 **409**；
  - 仍被任务计划种子（`tasks.plan_seed_json`）引用时返回 **409**；
  - 拦截解除后可再次删除。
- 模板列表补充 `usage_count`、`active_workflow_count`、`active_seed_count`；前端只展示活跃模板，删除入口位于模板库工具栏（发布按钮之后），删除前二次确认。
- 模板库头部改为「搜索行 + 新建/导入操作行」的紧凑响应式布局；移除无实际用途的状态筛选与已归档分组。

## 修复：任务详情工作流页不显示

- 根因：Cindy 规划并生成 workflow、human 落板后，任务详情只更新草案列表，未主动刷新 workflow；点击「工作流」页签也不重新拉取。旧实现还会把所有请求错误都当成“没有工作流”，旧请求晚到的 404 可能覆盖新请求的成功结果。
- 修复：
  - 批准/应用工作流草案后显式刷新 workflow；
  - 点击「工作流」页签时重新拉取；
  - workflow 请求增加序号保护，只接受最后一次响应；
  - 区分加载中、加载失败（带「重试」）、真正无 workflow 三种状态；
  - 已有数据时刷新失败保留上次成功数据，并在顶部显示错误横幅；
  - 切换任务时重置 workflow、历史与错误状态。
