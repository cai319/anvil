# Anvil v1.42.7 — 默认 Cindy 助理、首次安装清理与 assign 修复

> 发布日期：2026-11-13
> 版本：1.42.7

## 1. 默认 Cindy 规划助理

- 后端启动时幂等创建内置 onboarding 助理 Cindy，不再等到首次规划任务才懒加载；
- 默认画像包含：
  - `kind=onboarding`
  - `working_mode`
  - `skill_description`
  - `capabilities`
  - `responsibilities`
  - 完整的规划助理 `system_prompt`
- 旧版 Cindy 只有 `kind` 时，启动时补齐缺失画像字段，不覆盖已有自定义值；
- 新增幂等接口 `POST /api/v1/roles/onboarding/ensure`；
- `anvil init` 会调用该接口确认 Cindy 就绪。

## 2. 首次安装不再生成旧模板数据

- 移除 `anvil init` 自动创建 `main` 频道的默认行为；
- 移除 `anvil init --with-roles` 及 developer / tester / reviewer 模板角色；
- 全新安装默认只有 Cindy，工作区列表为空；
- README 首启说明同步更新：频道和角色按需创建。

## 3. assign 规划期锁修复

- `assign_roles` 只在角色既在执行、又持有活跃 claim 时拒绝重新绑定 Roster；
- `plan_first=true`、Roster 为空时，Cindy 自身规划 run 不再阻止 `anvil task assign`；
- `/tasks/{id}/assign-existing` 捕获 `ConflictError` 并返回 409，不再出现 500；
- 新增 planner 运行、活跃 claim 两条回归测试。

## 4. UI 细节

- 角色头像阴影使用独立色：橙色 `#f97316`，红色 `#b91c1c`，加大橙红色差；
- 新增 Anvil favicon（黄底、黑色 Anvil 图标、红色阴影）；
- `index.html` 引用 `/favicon.svg`。
