# Anvil v1.44.0 — 旁路验证节点、按步骤 subagent 提示与 Windows 编码加固

> 发布日期：2026-11-21
> 版本：1.44.0

## 1. 工作流旁路验证节点（external_nodes）

- 修订 intent 新增 `external_nodes`：把验证/复测节点挂在 loop 之外，不打断切片闭环；
- 节点可指定 `role`、`depends_on`、`target_slice_id` 或 `target_step_id`，以及
  `restart_scope=target|downstream`，只重跑目标或其下游；
- 新增 `safe_external` 修订分类，与切片修订互斥；workflow 已 done / task in_review 时，
  可把目标拉回进行中再执行旁路验证；
- scheduler 清理失效的 workflow_revision 草案（workflow terminated/done、task done、TTL 超时）；
- workflow 生命周期锁、任务删除时终止运行中 workflow、评审阻塞检查与自动收尾同步补齐；
- 前端图谱、CLI `workflow revise`、设计文档同步。

## 2. 按步骤的 subagent_hint

- `workflow_steps.subagent_hint` 由 Cindy 在 workflow/loop 阶段显式决定；
- 只有步骤标记该字段、且运行时声明 `supports_subagents=true` 时，才把
  `SUBAGENT_PROTOCOL` 注入投影文件；
- agent 草案必须为每个写出的 loop 阶段显式写 `true/false`，漏写/非布尔会拒绝；
- 审批入口再次校验旧草案/人工修改；运行期切片计划不得覆盖 hint；
- 静态 step、loop 阶段和动态切片生成步骤均继承。

## 3. Windows 编码与日志截断加固

- 解码使用 `locale.getencoding()` 获取真实 ANSI 代码页（忽略 UTF-8 mode）；
  GB18030 增加结构判据，避免把 `Grüße` 等西文误判为中文；正确剥离 UTF-16/32 BOM；
- run log 只 seek 读取末尾 200KB，截断点对齐完整行/字符，丢弃并发追加的末尾半字符；
- Windows 子进程强制 UTF-8 stdio，覆盖父环境/runtime 旧值；one-shot/daemon/utility/MCP 探测统一；
- 角色与用户文件统一 `read_text_file`（UTF-8/UTF-16/GBK，保留 universal newline），写入仍 UTF-8；
- CLI 非 TTY 输出固定 UTF-8；`--content-file/--file` 自动识别编码并剥离 BOM；
- 新增编码/截断/环境覆盖测试，更新 troubleshooting 与 implementation-status。

## 4. 同期合入

- 默认创建 Cindy 规划助理，首启不再生成旧模板角色/频道；`POST /roles/onboarding/ensure` 幂等；
- 修复规划者 run 误阻止 Roster 绑定；`/tasks/{id}/assign-existing` 状态冲突返回 409；
- UI favicon、角色头像橙/红色差修正。

## 5. 验证

- 后端全量 `pytest tests -q` 通过；
- 前端 `npm run build` 通过。
