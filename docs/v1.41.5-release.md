# Anvil v1.41.5 — Finding 详情标题与分条展示修复

> 发布日期：2026-11-06
> 版本：1.41.5

## 1. 标题多行与关闭按钮

- finding 详情抽屉标题支持多行；
- 标题列设置 `min-width: 0`，长标题不再挤压关闭按钮；
- 关闭按钮固定 `26×26`、不参与 flex 收缩，并固定在右上角；
- 长中文/英文 token 使用 `overflow-wrap: anywhere` 正常换行。

## 2. 分条内容展示

仅前端展示，不修改 finding 原始内容：

- 严格识别连续条目编号链 `1 → 2 → 3`；
- 只在编号前最近的非空白字符是分隔符（或已有换行）时拆行；
- 同一条内容内部的多个分隔符不会触发拆行；
- 支持中英文格式：
  - `（1）`、`(1)`、`【1】`、`[1]`
  - `1.`、`1、`、`1)`
  - `一、`、`二、`
  - 分隔符 `；;：:，,。.`
- 避免把 `1.2.3` 等版本号误判为列表。

## 3. 验证

- 前端口径构建通过；
- 实际长标题换行 4 行时关闭按钮保持 `26×26`；
- 分条字段按条目换行展示，原始内容与 API/导出数据不变。
