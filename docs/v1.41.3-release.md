# Anvil v1.41.3 — 日志级别按业务收敛

> 发布日期：2026-11-05
> 版本：1.41.3

## 1. 日志级别策略

默认 `ANVIL_LOG_LEVEL=INFO`，按业务重要性分级落盘：

| 场景 | 级别 | 默认落盘 |
|---|---|---|
| 成功的 GET / 页面轮询 | `DEBUG` | 否 |
| 变更操作（POST/PUT/PATCH/DELETE） | `INFO` | 是 |
| 4xx（权限/参数/不存在） | `WARNING` | 是 |
| 5xx / 未捕获异常 | `ERROR` + traceback | 是 |
| Tracker 发送/响应 | `INFO` | 是 |
| Tracker 超时/连接失败 | `WARNING` | 是 |
| httpx/httpcore 自带逐请求 INFO | 提升到 `WARNING` | 否 |

- Tracker 请求固定直连：`trust_env=False`、`proxy=None`；不读取环境代理或
  Windows/macOS 系统代理。
- 需要排查轮询时可临时设置 `ANVIL_LOG_LEVEL=DEBUG`。
