# Anvil v1.48.2 — finding 确认弹窗加固与外部编号徽标统一

> 版本：1.48.2（前端 UI 修复；无后端/CLI 行为变更）

## 修复

- **“确认真实问题”点击无反应**：确认弹窗打开后，双击或在约 450ms 后再点一下，会落在刚挂载的遮罩上并把弹窗立即关闭。遮罩守卫从 400ms 延长到 **900ms**，并忽略双击产生的 `detail > 1` 第二下，覆盖 Windows 慢速双击设置。
- **极早点击保护**：DialogHost 尚未挂载时，确认请求先进入缓冲队列，挂载后立即消费，避免 Promise 永久悬挂。
- **Enter 确认**：备注输入框支持 Enter 直接提交，不必只依赖按钮。
- **外部编号尺寸**：`外部 #xx` 从深色主题的 `.chip` 改为 `.finding-tag finding-external-badge`；`.finding-status` 统一 `inline-flex` 与 `line-height: 1.2`。现在“待确认 / 置信度 / 外部 #xx”三类徽标均为 10px 字号、`2px 7px` 内边距、18px 高。

## 验证

- 前端 `npm run build`（`tsc` + Vite）通过。
- 无头 Chrome：单击打开；300/450/600/800ms 后双击或再次单击保持弹窗；超过保护窗口后点遮罩正常关闭；抽屉保留。
- 徽标计算样式：状态、标签、外部编号三者 `font-size: 10px`、`padding: 2px 7px`、高度 `18px`。
- 数据库验证：在线上数据库副本上调用重构后的 `confirm_finding`，finding 由 `submitted` 变为 `confirmed`，线上数据库未改动；问题与数据库/重构无关。

## 升级

- 替换前端静态资源并重新构建；版本文件统一为 `1.48.2`，`anvil --version` 输出 `1.48.2`。
- 无 API、数据库、调度或 CLI 命令变更。
