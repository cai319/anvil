## 1. 协作方式判断（subagent / mention / 委派 / 派遣）

- `STEP_PROTOCOL` 新增 `COLLABORATION_PROTOCOL`，把四类协作方式的边界写成 Q1–Q5 判断：
  - workflow 已由其他步骤承担：对应步骤已执行/执行中 → mention；尚未启动且当前阻塞 →
    记录 workflow 缺口 + @cindy/@human，评估是否新增委派；尚未启动且不阻塞 →
    `context_note` 带入后续步骤上下文；
  - 阻塞当前 step：自己做 / 同角色只读 subagent / 仅评审 mention / 另一角色独立交付委派；
  - 非阻塞：需要另一角色且独立上下文 → dispatch；否则 mention/记录；
  - 需要改 workflow/角色/顺序 → @cindy；不可逆 → @human。
- `DISPATCH_PROTOCOL` 明确非阻塞、不等待、回切仅在原切片 running 时尝试；
- `DELEGATION_PROTOCOL` 明确阻塞式独立交付、workflow 已排定先走对应步骤、禁止同角色委派；
- 生成的 static/dynamic slice 步骤追加 `SLICE_COLLAB_RULE`（恰好一次）；
- CLI `task`/`step` 帮助同步新判据。

## 2. 未来步骤上下文（context_note）

- 新增 `tasks.context_note`、`POST /tasks/{id}/note`、`anvil task note --for-step`；
- 写入 task-wide、system 作者（`slice_key=NULL/role_slug=NULL`）的 comment 活动：
  任意未来 slice/角色 unread 可见，不产生 mention、不唤醒、不误判 HITL。

## 3. 最终审批角色一致性

- `preview_participant_sync` + `GET /board/drafts/{id}/participants` 预览；
- 审批时自动把 workflow 中出现、尚未绑定的现有角色加入任务参与者，响应返回
  `participants_added`；
- human 指定但 workflow 未安排的角色阻止审批；
- loop/slices 与 flat 都校验最终 `workflow roles == task participants`；
- 修订新增角色同步成为参与者；`set_assignees` 移除 running workflow 引用角色被拒；
- 规划协议改为“human 角色必须参与，其余 slice 从系统现有角色合理分配”。

## 4. 委派/派遣/wake 可靠性

- 同角色委派拒绝（自锁）；
- step 最终失败 / execution 终止 / 父任务 cancel 关闭 open 委派并唤醒父 step；
- 任务级 submit/review 按最新 execution 作用域，旧委派不阻塞新执行；
- `wake_requests` 持久化队列：running 目标 note 持久化 + 重试、pump 失败回 pending、
  HITL/终态门禁、run-missing 释放 lease、pending 唯一/新 note 覆盖；
- 派遣创建先幂等去重再治理；governance 失败不退化 reply run；
- `_refresh_unread_block` 使用精确边界，修复截断 STEP_PROTOCOL；inbox CLI `--task` 修正。

## 5. 运行时 subagent 观测（D3）

- `schema.subagents_v2`：`subagent_type/proc_generation/native_session_id/
  parent_tool_use_id/slice_key/step_id/interrupt_reason`；
- turn 结束 → `interrupted(turn_ended)`；晚到 tool_result CAS；重复 tool_use 不重置终态；
  daemon 重启自愈；scheduler 孤儿 reaper；任务删除清理；
- 只读 API：`GET /runs/{id}/subagents`、`GET /roles/{slug}/subagents`、
  `GET /tasks/{id}/subagents`；`anvil subagent list --run|--role|--task`；
- 状态机隔离契约测试：决策逻辑不读 subagent。

## 6. subagent_hint 契约（D4）

- 所有 hint 载体（flat/静态 slices/loop/external_nodes/revision）能力感知：runtime 不支持时

- 执行侧漂移写一次性 `subagent_hint.skipped`；
- Roster 展示 `supports_subagents`；PLANNING/REVISION 协议补能力规则；
- 协议拆通用只读调查 + 安全审计 checker（仅问题板 reviewer 注入）；
- 前端步骤卡徽章与模板/草案编辑器 hint 复选框。
