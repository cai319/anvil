# 角色状态与颜色模型统一设计

> 日期：2026-11-11
> 范围：任务卡、任务内角色会话、角色运行时、工作状态卡片、实时会话、workflow slice

## 1. 目标

统一所有角色状态的取数来源、优先级和颜色，避免同一个角色在不同页面显示不同状态。

核心原则：

1. **任务内视角**回答“角色是否投入当前任务/切片/子任务”。
2. **全局视角**回答“角色整体上现在是否在工作”。
3. **slice/step 视角**只表达工作流自身状态。
4. 头像、点灯、徽标、slice 圆点使用同一套五色语义，不各自维护映射。

## 2. 五色语义

| 颜色 | 含义 |
|---|---|
| 橙 | 正在处理 / 执行中 |
| 黄 | 等待人工评审或确认 |
| 红 | 需要关注：排队、繁忙、失败、返工 |
| 绿 | 空闲、完成、成功 |
| 灰 | 未开始、未参与、已释放、已终止、未知 |

颜色只表达语义，不表达领域。领域由组件位置和文案区分。

## 3. 任务内角色状态

使用位置：

- 大厅任务卡角色头像
- 任务详情「参与角色」工作状态卡片
- 任务详情「角色运行时」角色行
- 任务内对话头像
- 任务内角色会话

取数来源：

- 角色 runtime（`alive/status/current_task_id/current_slice_key/queue_*`）
- 当前任务在当前角色/切片上的 run
- 当前任务/切片的 workflow step 状态
- 角色 claim 仅作为无运行时信息时的兜底

状态与优先级：

| 优先级 | 状态 | 颜色 | 条件 |
|---|---|---|---|
| 1 | 进行中 | 橙 | 角色正在本任务/切片执行（`busy && current_task_id === task`，或本任务 open step 且上下文仍在此任务） |
| 2 | 失败 / 返工 | 红 | 本任务 step/run `failed` 或 `rejected`，且角色当前未在本任务执行 |
| 3 | 排队中 | 红 | 本任务或其委派/派遣子任务存在等待该角色的队列项（无论来自 `@`、其他角色委派、指派、回复还是切片切换），或正切换到本任务 |
| 4 | 等待人工 | 黄 | 本任务 step/run 为 `submitted/reviewing`，且角色当前未在本任务执行 |
| 5 | 完成 | 绿 | 任务完成，或该角色在本任务的所有步骤/claim 已完成 |
| 6 | 空闲 | 绿 | 角色存活，本任务上下文仍保留，但没有待处理工作 |
| 7 | 待办 | 灰 | 角色在本任务有 claim/步骤但尚未开始 |
| 8 | 未参与 | 灰 | 角色在别处工作且本任务没有排队；或本任务没有该角色上下文 |
| 9 | 已释放 / 已终止 | 灰 | claim 已释放且无活跃上下文，或任务/步骤已终止 |

说明：

- 任务已终止/已完成时，若角色已不在本任务执行，分别显示灰色「已终止」/绿色「完成」，不被历史 failed run 或残留队列覆盖；若角色仍在本任务执行，仍以橙色「进行中」为最高优先级。
- 角色在别的任务忙，但本任务没有排队 → **未参与（灰）**，不再显示红色“繁忙”。
- 角色在别的任务忙，但本任务有排队 → **排队中（红）**。
- 核心判定：只要有事物在等待该角色从其他任务释放后处理，且该事物属于本任务或其委派/派遣子任务，本任务显示红色「排队中」。
- 队列项不区分来源：`@` 提及、其他角色委派、指派子任务、回复消息、切片切换、派遣任务都算。
- 任务内排队统计使用任务级队列（不限当前 slice），并合并该任务下委派/派遣子任务的该角色队列；工作状态卡片的详情文案可以继续显示具体 slice/子任务。
- 队列归属规则：先按 `task_id` 直接匹配；委派/派遣子任务按 `parent_id` / `source_task_id` 归属到来源任务。实现时需要让 `taskRoleState` 能拿到当前任务及其子任务 id 集合。
- 如果队列项属于与本任务无关的其他任务：本任务显示灰色「未参与」；全局实时会话卡仍显示红色「排队中」。
- `claim.released` 不得覆盖“正在本任务执行”。
- 工作状态卡片中的头像阴影、点灯、状态徽标必须使用同一个 tone。

## 4. 全局角色状态

使用位置：

- 大厅右侧「实时会话」角色卡
- 角色执行历史页顶部

取数来源：

- runtime 当前状态
- 当前/最近 run
- 全局队列

状态：

| 优先级 | 状态 | 颜色 | 条件 |
|---|---|---|---|
| 1 | 进行中 | 橙 | 角色正在任意任务或系统任务中执行，显示当前任务 |
| 2 | 失败 | 红 | 当前/最近 run 失败 |
| 3 | 排队中 | 红 | `queue_len > 0`，或存在等待该角色从其他任务释放后处理的队列：`@`、委派、指派子任务、派遣、回复等 |
| 4 | 等待人工 | 黄 | 有 submitted/reviewing 的 run，且没有执行中的工作 |
| 5 | 空闲 | 绿 | 进程存活且没有执行中任务 |
| 6 | 等待唤醒 | 灰 | 进程已退出但保留上下文 |
| 7 | 未运行 | 灰 | 进程已退出且无上下文 |

全局实时会话卡的头像阴影和指示灯使用同一个 tone。历史 run 不得单独把角色头染成“运行中/待审核”。

## 5. Slice / Step 状态

Step：

| Step 状态 | 颜色 |
|---|---|
| pending | 灰 |
| running | 橙 |
| submitted | 黄 |
| approved | 绿 |
| rejected / failed | 红 |
| skipped | 灰 |

Slice 聚合优先级：

```text
failed > rejected > running > submitted > 全部 approved/skipped > pending
```

规则：

- 有步骤提交待审 → slice 黄色，不再合并成 running。
- 有步骤运行中 → 橙色。
- 有步骤失败/驳回 → 红色。
- 全部步骤完成 → 绿色。
- 仅有部分步骤完成、其余仍 pending → 灰色待办，不显示橙色进行中。

## 6. 组件映射

| 组件 | 状态函数 | 头像 | 点灯 | 徽标 |
|---|---|---|---|---|
| 任务卡角色头像 | `taskRoleState` | tone | 无 | 无 |
| 任务详情参与角色 | `taskRoleState` | tone | tone | tone |
| 任务内角色会话行 | `taskRoleState` | tone | tone | tone |
| 任务内对话头像 | `taskRoleState` | tone | 无 | 无 |
| 大厅实时会话卡 | `globalRoleState` | tone | tone | 文本状态 |
| 角色执行历史页顶部 | `globalRoleState` | tone | tone | 文本状态 |
| Workflow slice / step | `workflowStatusTone` | 无 | slice 圆点 | step 徽标 |

不再在页面内各自写 `runStatusClass` / `roleStatus` / `statusClass` 映射。

## 7. 样式统一

- `.role-live-dot` 只保留一份定义，使用 `orange/yellow/red/green/gray` 五类。
- `.status-light` 使用同一套 tone 类。
- `.role-avatar` 使用 `data-role-tone` 五类，不再接受 `running/submitted/released/blue/amber` 等混合 key。
- 删除 `amber`、`blue` 兼容别名和重复的 `role-live-dot` 定义。
- `STATUS_META` 不再硬编码独立色值；使用统一的 tone token 或 CSS class。
- run 生命周期徽标单独保留，但色值映射与五色一致：
  - created/projecting/running → 橙
  - submitted/reviewing → 黄
  - completed → 绿
  - failed → 红
  - abandoned/closed/suspended → 灰

## 8. 验收场景

1. 角色在其他任务工作，本任务无排队：任务卡、任务内会话、工作状态卡片均显示灰色「未参与」。
2. 角色在其他任务工作，本任务或其委派/派遣子任务有排队（`@`、委派、指派、派遣、回复均可）：以上位置显示红色「排队中」。
3. 其他角色委派/指派了一个子任务给该角色，但该角色正在其他任务执行：来源任务显示红色「排队中」，全局实时会话卡也显示红色「排队中」。
4. 队列项属于与本任务无关的其他任务：本任务显示灰色「未参与」，全局实时会话卡显示红色「排队中」。
5. 角色正在本任务执行：头像、点灯、徽标均为橙色「进行中」，不受 claim released 影响。
6. 本任务等待人工：角色不在执行时，头像、点灯、徽标均为黄色「等待人工」。
7. 本任务完成且角色无活跃执行：统一为绿色「完成」。
8. 大厅实时会话卡只看全局：角色在任意任务工作显示橙色「进行中」，有任意排队显示红色「排队中」，空闲绿色，退出灰色。
9. 一个 slice 的所有步骤已提交：slice 显示黄色，不再显示橙色。
10. 一个 slice 只有部分步骤完成、其余 pending：slice 显示灰色待办，不显示橙色。
11. 同一状态在任务卡、任务内会话、工作状态卡片、点灯、头像中的色值完全一致。

## 9. 非目标

- 不改变后端任务/claim/run 的状态机。
- 不改变页面布局和信息密度。
- 不把所有任务状态都塞进角色头像；任务自身状态继续由任务列和任务状态徽标表达。
