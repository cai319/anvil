# Anvil v1.48.1 — 问题板确认弹窗与主题知识库视觉修复

> 版本：1.48.1（前端 UI 修复与重设计；无后端/CLI 行为变更）

## 修复

- **问题板确认弹窗“点击没反应”**：连点/双击“确认真实问题”时，第二次 `mousedown` 落在刚挂载的遮罩上，确认弹窗立即关闭。新增 400ms 遮罩关闭守卫（`dialogGuard`），确认弹窗与 finding 抽屉共用；弹窗打开时 Escape 只取消弹窗，不再连带关闭抽屉。

## 重设计

- **左侧主题栏**：白色主题卡改为深色导航卡（`ink-800` 栏体 + `ink-700` 卡片）；选中态使用黄色描边、左侧 3px 黄色竖条和黄色主题名；元信息、`待复核`、`chip` 改为深色背景下的可读配色；`新建` 改为 `ghost` 描边按钮。
- **主题知识卡**：取消整张白色列表纸，改为独立纸张卡（`paper-3` 表面、2px 墨色描边、硬阴影）；补齐纸面 `chip`、authority、quality、`status-closed`、`muted` 等高对比配色。
- **查看完整知识卡**：移入卡片页脚，改为描边按钮 + `chevron-down` / `chevron-up`，并带 `aria-expanded`；右侧保留原有批准、编辑、清洗、拒绝、收割、反馈、晋升等操作；窄屏自动换行。
- **展开阅读区**：改为全宽纸面阅读区，字段与正文统一纸面主题，不再出现白列表+深正文的混搭。

## 验证

- `dev/frontend`：`npm run build`（`tsc` + Vite）通过。
- 无头 Chrome 1512×982 与 768px：深色导航卡 hover/焦点/选中、纸张卡、展开/收起、页脚按钮换行、无横向滚动、无 console error。
- 通过 CDP 拦截 `knowledge/repo-cards` 与 `knowledge/task-cards` 注入 proposed/approved/rejected/任务级样例卡验证，未向真实知识库写入数据。
- 角色知识页签回归：原有白色列表样式不受主题作用域影响。

## 升级

- 替换前端静态资源；版本文件统一为 `1.48.1`，`anvil --version` 输出 `1.48.1`。
- 无 API、数据库、调度或 CLI 命令变更。
