# Anvil v1.50.0 — 角色 RSI 自进化、隐藏回放评估与运行时改进提案

> 发布日期：2026-11-25
> 版本：1.50.0
> 分支：`rsi`
> 设计文档：`docs/v1.50-role-rsi.md`
> Spec：`docs/superpowers/specs/2026-11-24-anvil-role-rsi-spec.md`

## 1. 版本主题

v1.50 把角色从“静态画像 + 人工改配置”升级为**有边界的自进化闭环**：

```text
任务 done / 驳回 / 步骤失败 / 返工
  → observation（确定性、幂等）
  → 空闲窗口反思（独立上下文）
  → 知识卡 / 策略候选 / 角色提案 / 运行时提案
  → 静态门 + 可选隐藏回放评估
  → 人工批准 → active 演进版本
  → SOAKING 实际指标 / 自动回滚
```

默认全部关闭；按角色 `definition.rsi.enabled` 试点。任务执行、RSI 反思、L2 评估三套
上下文隔离，评估器与隐藏集不在角色可写面内。

## 2. 角色 RSI

- **画像分层**：Charter（definition/tools/instruction Charter 段）只读/只提案；
  Strategy（instruction 策略段/PRINCIPLES/playbooks）人工审批；Experience（角色知识卡）
  按检索进入上下文。
- **完成回执**：每个 done 任务为参与者写幂等 `rsi.observation`；驳回、步骤失败、返工
  也进入证据链。
- **按角色试点门**：全局 `role_rsi` + 角色 `definition.rsi.enabled` 同时为 true 才生效；
  演化页可开关，未启用角色不写观测、不反思。
- **反思 worker**：`origin=rsi_reflect`、`__rsi_reflect__` 独立槽、每 cycle 新会话、
  任务唤醒可抢占；证据包脱敏 token/密钥/home 路径，不含 held-in/held-out。
- **输出自动入库**：知识卡、审批档候选、画像提案、运行时提案；每 run 只入库一次，
  写 `rsi.reflection_ingested`；失败/解析失败可审计。
- **有界算子**：≤2 edits/candidate、≤400 字符、固定算子目录、portrait_refs/
  diagnosis_ref/预测效果；tier 由算子目录派生，不能通过输出降级。
- **策略锁**：`role_rsi_lock_strategy` 开启后，Agent 直写 instruction 被拒；追加准则转
  pending 候选；human 直写仍可用。

## 3. 评估算法

- **隐藏回放集**：人工策展真实完成任务的 item，held-in/held-out family 不相交，
  最低 8+8；item 内容只在隔离文件，角色不可见。
- **L2 ReplayRunner**：shadow home + 临时 workspace + 角色 runtime + evaluator 执行隐藏
  verifier；无 `ANVIL_ENDPOINT/TOKEN/EVAL_KEY`、设置 `ANVIL_EVAL_MODE=1`、真实 home
  前后 hash 校验；forbidden diff/token cap/超时门。
- **配对统计**：baseline/candidate 同 item 两臂；按 family 分层 bootstrap；A/A 噪声
  门槛；MDE；三态 `promote/reject/inconclusive`；candidate hard/forbidden 才否决。
- **评估队列**：`eval_runs.request_json` + `EvalWorker` 单并发；完成把候选置
  pending（promote/inconclusive）或 rejected；promote 仍必须人工批准。
- **默认关闭**：回放需要人工准备 suite、耗 token；数据不足只返回 inconclusive。
  `role_rsi_replay_l2` 是预留开关，实际执行由 `role_rsi_evaluation` 控制。

## 4. 版本与存档

- **演进版本** = 完整角色空间快照：Strategy + Experience 文件/知识卡 + Charter
  definition/digest；支持切换、应用前 diff、导出/导入。
- **配置修订** = 手动配置历史：definition + instruction/PRINCIPLES + `role_tools_json`；
  默认隐藏；支持恢复、按 content_hash 去重、重复项清理。
- **压缩 CAS**：zlib/raw blob + manifest/逐文件 hash + `verify_version` + GC；
  损坏版本不自动删除，切换前校验。
- **应用版本**：非 active “应用”/active “重新应用”调用同一 switch，先展示文件
  added/modified/unchanged、知识卡恢复/归档/人工保留、Charter 差异、工作集；确认后
  才执行，不重跑评估。
- **配置恢复**：恢复 definition/策略文件/工具快照，不改变 active evolution；
  legacy 修订给 warning；写 `role.config_restored`。
- **导出/导入**：`role-<slug>-vN-<hash8>.anvil.zip`，含 export/manifest/charter/files/
  README；导入 `new_role`/`add_version`，不自动启用/切换；hash、zip-slip、大小、
  依赖、Charter diff 校验。

## 5. 运行时改进提案（RIP/RTP）

- 角色遇到 skill/MCP/runtime YAML/feature flag/tool preset/model/environment 等
  自己不能改的运行时问题，生成带证据、根因假设、建议修改、验收方式的 Markdown 提案。
- DB `runtime_proposals` + `data/runtime-proposals/<id>/proposal.md`；工具治理页/Inbox
  可查看、人工流转、导出。
- 生命周期 human-only：`draft→open→triaged→accepted→implemented→verified→closed`，
  另有 rejected/duplicate/wontfix/stale；Agent 只能 draft/追加证据。
- 自动检测器默认关闭：确定性扫描 missing/unhealthy runtime 和
  timeout/spawn_error/context_overflow run，只建 draft/追加证据；当前失败 run 按
  run_id 生成，未按错误模板跨 run 聚合。

## 6. 调度、API、CLI、UI

- scheduler 新增第 11 域 `evolution`：反思派发/reap/SOAKING 检查/运行时检测；
  受全局活跃 run 上限、角色忙碌和配额约束。
- API：`/rsi/*`、`/runtime-proposals/*`、角色版本 list/summary/diff/switch/baseline/
  purge/dedupe-config/export/restore-config、`/roles/import*`。
- CLI：`anvil rsi`、`anvil runtime`、`anvil role export|import`。
- UI：角色工坊“演化”页（基线/工作集/候选/评估/版本/应用 diff/导出/导入/清理）、
  工具治理运行时提案板、Inbox `rsi_candidate`/`runtime_proposal`。

## 7. 安全与默认姿态

- 晋级/切换/purge/导入/RIP 流转/导出 human-only；Agent token 403。
- 默认：`role_rsi=off`、`role_rsi_evaluation=off`、`role_rsi_rubric_judge=off`、
  `role_rsi_replay_l2=off`、`runtime_proposal_detector=off`；
  `runtime_proposals=on` 只生成文档。
- 候选/评估不自动晋级；inconclusive 永不自动应用；RIP 永不自动应用。
- 隐藏集隔离主防线为独立目录/ACL/不暴露路径；加密为可选加固，默认关闭。

## 9. 已知边界

- P6 试点（2–3 个真实角色、4 周）尚未执行；阈值、UX、token 预算需按真实数据调优。
- 自动检测器尚未按错误模板跨 run 聚合，且为每 tick 扫描而非严格每日。
- `role_rsi_replay_l2` 与 `role_rsi_evaluation` 的职责待后续合并/拆分明确。
- 导出包 `charter.json` 的 tools 取导出时当前值；严格版本复现需后续纳入 evolution
  版本工具快照。
- 隐藏集加密默认关闭；拥有本机 shell 的恶意 Agent 残余风险已声明。

## 10. 升级

1. 更新代码后安装/升级后端与 CLI（editable：`pip install -e dev/agentcli`）。
2. 重启后端；启动迁移幂等，自动补 `role_versions`/`proposals`/`eval_runs`/
   `runtime_proposals` 字段。
3. 重建前端 `npm run build` 或使用发布包。
4. 默认行为不变；先按权限/角色团队决定是否开启 `role_rsi`，再按角色试点。
5. 版本文件统一为 `1.50.0`；`anvil --version` 应为 `1.50.0`。
