# v1.60.1 修复：任务角色下拉与 PoC 实时日志

发布日期：2026-11-28　类型：patch

## 修复

1. **任务页「选择角色」下拉显示不全**
   - 根因：`select` 继承正文 `--fs-base`（15–24px），相邻按钮使用 `--fs-control`（12.5–15px），
     在 30–36px 高的控件里溢出并裁切长角色名。
   - 修复：`.session-actions select` 使用 `--fs-control`、`line-height: 1.25`、
     `max-width: min(280px, 100%)`、`min-width: 0`、`text-overflow: ellipsis`。
   - 仅影响任务详情指派角色选择器；颜色、边框、focus ring、间距不变。
2. **PoC 作业运行中日志为空**
   - 根因：`log_dir/artifact_dir` 只在作业结束时写入，运行中 `anvil poc logs` 找不到文件。
   - 修复：worker 领取作业（claim）时即写入 `log_dir`、`artifact_dir`、`backend`；
     `job_log` 对历史行提供作业目录回退。运行中的“日志”按钮现在可见 podman/docker 命令与构建输出。
