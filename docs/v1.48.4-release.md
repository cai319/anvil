# Anvil v1.48.4 — finding 详情居中弹窗与尺寸调整

> 版本：1.48.4（前端 UI 调整；无后端/CLI 行为变更）

## 调整

- **居中弹窗**：安全 finding 详情从 v1.48.3 的右侧抽屉改回屏幕中部弹窗；overlay 恢复居中与 16px 外边距。
- **弹窗外观**：沿用应用弹窗语言——3px 墨色描边、14px 圆角、硬阴影；头部/底部固定，中间内容滚动。
- **尺寸放大**：桌面 `min(1200px, 94vw) × min(960px, 94vh)`，1512×982 下实际约 `1200×923`；窄屏 `94vw × 92dvh`，保留四周留白与圆角。
- 报告式内容保持不变：5 项判定摘要、浅色人工决策记录、问题定位卡、单一面板详细信息。

> v1.48.3 发布说明中的“右侧抽屉、约 900px”是当时的实现，v1.48.4 起以居中放大弹窗为准。

## 验证

- `npm run build`（`tsc` + Vite）通过。
- 1512×982：弹窗 `1200×923` 居中，左右 156px、上下 29px；摘要 5 项一行；无横向溢出。
- 768px：弹窗约 `722×923` 居中，摘要 3+2；760px：`714×903`，摘要 2+2+1；详细字段堆叠，无横向滚动。
- 线上 `dist` 已重建；浏览器强刷后生效。

## 升级

- 替换前端静态资源；版本文件统一为 `1.48.4`，`anvil --version` 输出 `1.48.4`。
- 无 API、数据库、调度或 CLI 命令变更。
