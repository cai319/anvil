# Anvil v1.48.5 — finding 详情弹窗尺寸再放大

> 版本：1.48.5（前端 UI 调整；无后端/CLI 行为变更）

## 调整

- 桌面尺寸改为 `min(1320px, 95vw) × min(1200px, calc(100vh - 24px))`，1512×982 下实际约 **1320×958**；相比 v1.48.4 的 1200×923，宽度 +120，上下留白从 29px 收紧到 12px。
- 正文可视高度从约 721px 提升到约 780px；更高的屏幕上弹窗高度会继续增长到 1200px。
- 窄屏改为 `95vw × calc(100dvh - 24px)`，保留 12px 边距和圆角。
- 报告式内容与居中弹窗外观保持不变。

> v1.48.4 的 `1200×923` 是上一版尺寸；v1.48.5 起以本说明为准。

## 验证

- `npm run build`（`tsc` + Vite）通过。
- 1512×982：弹窗 `1320×958` 居中，摘要 5 项一行，标题单行，正文可视高度约 780px，无横向溢出。
- 768px：弹窗约 `730×958`，摘要 3+2；760px：`722×958`，摘要 2+2+1；均无横向滚动。
- 线上 `dist` 已重建；浏览器强刷后生效。

## 升级

- 替换前端静态资源；版本文件统一为 `1.48.5`，`anvil --version` 输出 `1.48.5`。
- 无 API、数据库、调度或 CLI 命令变更。
