# Anvil v1.45.1 — 协作收尾：角色删除、dispatch 通知补投与 subagent 幽灵

> 发布日期：2026-11-21
> 版本：1.45.1（v1.45.0 的收尾修复）

## 1. 角色删除时关闭 open 委派

- 删除被委派角色前，先按“人工取消”语义关闭其名下 open 委派；
- 释放任务 claims、结束活跃 run，并唤醒父 step，避免父 workflow 永久等待一个
  已经不存在的角色。

## 2. dispatch 完成通知失败可补投

- `mention` 失败不再写 `task_dispatches.result_notified_at`；
- scheduler 新增 `retry_dispatch_notifications`：target task done 且未通知的 dispatch
  在 60s 退避后补投，成功后置位；
- 通知失败不再静默丢失。

## 3. 重复/重放 tool_use 不再污染内存 subagent

- `_track_subagent` 写入内存 active 前先查 DB 终态；
- `completed/interrupted` 的 subagent 不会被重复事件重新塞回 running 列表；
- DB 终态保持，实时视图与历史一致。

## 4. 验证

- 后端全量：`967 passed, 61 skipped`；
- 协作评测 offline 通过；
- 前端 `npm run build` 通过。
