# Anvil v1.41.1 — 问题板提交反馈 × tracker 超时/代理诊断 × CLI 帮助修复

> 发布日期：2026-11-05
> 版本：1.41.1

## 1. 问题板外部提交交互

- 「提交全部可提交问题」移到问题板标题栏右上角；窄屏自动换行。
- 提交完成后在问题板顶部显示结果：
  - 成功/失败数量；
  - 目标服务器地址、提交时间；
  - 成功条目的外部 ID；
  - 失败条目的 finding ID 与具体错误；
  - 可手动关闭。
- 全部成功使用绿色 `status` 提示；部分/全部失败切换为红色 `alert` 样式。

## 2. Tracker 超时与代理诊断

- 提交超时默认 30s，测试连接默认 10s，TCP 建连单独限制 5s：
  - `ANVIL_ISSUE_TRACKER_TIMEOUT`
  - `ANVIL_ISSUE_TRACKER_TEST_TIMEOUT`
  - `ANVIL_ISSUE_TRACKER_CONNECT_TIMEOUT`
- 超时错误区分阶段：
  - `ConnectTimeout`：无法建立 TCP 连接（DNS/防火墙/代理/端口）；
  - `ReadTimeout`：已连接但 tracker 未返回；
  - HTTP 504/502：tracker 或其上游网关返回。
- 测试连接结果增加 `elapsed_ms` / `error_type`；后端日志记录 endpoint、异常类型与耗时。
- 出站请求与 curl 行为一致：`trust_env=True`，读取
  `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`；未配置代理时由本机
  路由表选择出口网卡。可用 `ANVIL_ISSUE_TRACKER_PROXY` 显式覆盖环境变量。
- 工具页说明 base 地址的填写方式（如 `http://host/api` 或 `http://host:5000`），
  系统自动追加 `/draft/bulkCreate`。
- 排查文档新增 Q20，覆盖后端出站连通性、代理继承、tracker 504 与网关超时。

## 3. CLI 帮助与文档

- 补齐 `anvil knowledge -h` 的动作清单：
  `repo-create`、`repo-cards`、`card-create`、`card-approve/reject`、
  `quality`、`clean`、`feedback`、`review`、`explain`。
- 未知 knowledge action 的 `hint:` 改为使用统一的 `KNOWLEDGE_ACTIONS` 清单，
  避免新增命令后只更新一处。
- 新增 CLI 契约测试，保证 `-h` 和错误提示覆盖全部已实现动作。
- `docs/cli-reference.md` 增加缺失命令与「升级 CLI」说明（无 `anvil update`，
  editable 安装更新代码即生效）。
