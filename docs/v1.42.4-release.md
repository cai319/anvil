# Anvil v1.42.4 — 侧栏分组标题排版与开发方署名

> 发布日期：2026-11-10
> 版本：1.42.4

## 1. 侧栏分组标题排版

“工作台 / 角色与知识 / 系统”三处分组标题原先使用等宽字体 +
`0.16em` 大字号 + uppercase，与中文导航项的正文排版不协调。

调整：

- 改用 `--font-body` 正文字体；
- 响应式字号 `clamp(12px, 0.2vw + 9.2px, 17px)`，始终比导航项小一档；
- 字重 700、字距 `0.08em`；
- 使用 `--text-on-ink-muted`，保留次级标题层级。

## 2. 侧栏开发方署名

侧栏底部新增署名块，位于“收起侧栏”按钮上方：

```text
┌──────┐  DEVELOPED BY
│ ⚒    │  基站平台安全测试团队
└──────┘
```

- 新增 Lucide `anvil` 图标，放入黄色品牌方块（黑色描边、红色硬阴影），
  与左上角 Anvil 品牌牌使用同一套视觉语言；
- 第一行 `DEVELOPED BY`：等宽小字、`0.16em` 字距、弱化色；
- 第二行团队名：正文字体、700 字重、次级文字色；
- 桌面收起/图标栏模式只保留居中的 Anvil 图标；
- 移动端抽屉恢复完整图标 + 两行文字；
- 团队名单行省略，避免窄侧栏挤压布局。

## 3. 验证

- `npx tsc --noEmit` 通过；
- `npm run build` 通过；
- 本次仅前端改动，无后端/API/数据库变更。
