# Anvil v1.42.6 — 切片关联角色执行上下文

> 发布日期：2026-11-11
> 版本：1.42.6

## 1. 切片上下文入口

- Workflow 视图的每个切片行新增「上下文」按钮，不再只有当前切片可以查看角色上下文；
- 切片详情和静态步骤详情新增「查看角色上下文」；
- 点击后切换到任务详情的「角色运行时」页签，并定位到该切片对应的角色。

## 2. 角色运行时聚焦

- `TaskDetail` 保存 `{ role, sliceKey }` 聚焦目标，并透传给 `RoleSessions`；
- `RoleSessions` 等待 runs 加载完成后，按角色和 slice 找到最新 run：
  - 自动展开该角色行；
  - 加载日志和运行时上下文；
  - 高亮定位到的角色行；
- 如果该切片尚无 run，直接打开角色的「运行时上下文」面板，展示 contexts、session、cwd、队列和 subagents；
- 修复聚焦请求在 runs 尚未加载时提前应用、导致无法自动选中 run 的时序问题。

## 3. 设计演示

新增 `docs/demo/workflow-collaboration-demo.html`：

- 工作流总览 / 委派·派遣双视图；
- A/B/C 切片 chip 和甘特图切片行均可点击；
- 右侧 inspector 展示对应切片的角色执行上下文：
  - role、run、context key、session、phase；
  - 角色协议、任务、切片指令、知识、近期活动的上下文分层；
- 已完成、执行中、未开始切片使用同一套查看操作；
- 切回 workflow 节点时恢复节点详情，不残留切片上下文列表。
