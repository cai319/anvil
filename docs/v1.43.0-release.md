# Anvil v1.43.0 — subagent 提示编排、驳回唤醒与整体工程修复

> 发布日期：2026-11-13
> 版本：1.43.0

## 1. 按步骤的 subagent 隐性提示

- `workflow_steps` 新增 `subagent_hint` 字段（默认 0），由 Cindy 在 workflow/loop 阶段显式决定；
- 只有被标记的 step、且运行时声明 `supports_subagents=true` 时，才把
  `SUBAGENT_PROTOCOL` 注入投影文件；关闭时运行时的原生 subagent 仍然可用；
- 协议按 condition 拆分只读调查：单一 condition、结构化证据 JSON、确定性工具、
  父角色按条件逻辑聚合（不投票）；
- agent 提交的 workflow 草案必须为每个写出的 loop 阶段显式写
  `subagent_hint: true/false`，漏写或写非布尔值会被拒绝；
- 审批是另一条入口：批准旧草案/人工改过的草案时会再次校验，避免静默按 false 落库；
- 运行期 `slices.json` 不得覆盖 `subagent_hint`，提示编排权只属于 Cindy；
- 支持静态 step、loop 阶段和动态切片生成步骤继承。

## 2. 工作流草案驳回后唤醒作者

- 驳回 workflow/workflow_revision 草案后，自动唤醒草案作者（通常是 Cindy）重新规划；
- 驳回意见进入规划约束，提示作者优先用增量修订、不要原样复用被驳回的 tree；
- 修复此前只写 mention 活动、daemon 不轮询 activities 导致“驳回后无人接手”的问题。

## 3. 角色状态与大厅显示修复

- 新增 `GET /api/v1/tasks/status-summary` 批量接口，返回精简 workflow + 每个角色最近一次
  run（包含 completed/failed 等终态）；
- 大厅任务卡头像现在能显示失败/返工、等待人工；全局角色色调也参考终态 run；
- workflow step/slice 颜色统一走 `workflowStepTone` / `workflowSliceState`，减少重复映射；
- daemon 未启用时，runtime API 仍能从 `current_context_key` 还原当前 task/slice。
