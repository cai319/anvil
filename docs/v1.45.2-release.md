# Anvil v1.45.2 — 收件箱委派验收、审批参与者预览与评测实跑

> 发布日期：2026-11-21
> 版本：1.45.2（v1.45.1 的体验/评测收尾）

## 1. 收件箱直接处理委派验收

- human 收件箱新增「委派验收」页签：聚合 `type=delegation` 且 `status=in_review`、
  父任务仍活跃的工单；
- 展示父步骤、负责人、提交状态；可在收件箱直接「通过验收」或「打回」（复用现有
  delegation accept/reject 端点）；
- 验收/打回后条目自动消失，与委派工单的父 step 门禁保持一致。

## 2. 审批前预览参与者

- 任务详情的待审 workflow 草案显示「将新增参与者」与「human 指定但未安排的角色」；
- 数据来自 `GET /board/drafts/{id}/participants`（v1.45.0 已实现），提前暴露最终审批
  的参与者一致性结果，避免批准后才发现缺员/扩容。

## 3. 观测与边界修复

- 晚到 `tool_result` 增加 `proc_generation + native_session_id` CAS：旧会话/旧进程的
  迟到事件不再污染新记录（interrupted 只补结果，不伪装完成）；
- dispatch API 显式拒绝 `repo/workspace_id/base_branch` 覆盖（422），与 CLI 警告一致，
  不再静默忽略；
- flat/static step 的 `subagent_hint.downgraded` 审计补上 `task_id` 上下文。

## 4. 协作判断评测实跑

- `scripts/collaboration_eval.py` 支持 `--ids` 选择场景；
- 使用 `claude -p` 实跑 15 个场景：
  - **mode accuracy 100%**
  - **critical（未来步骤未启动/不唤醒、委派、禁止同角色委派、禁止 blocking dispatch、
    workflow 缺口）100%**
  - 总体 `ok=true`；
- 评测结果 JSON 可存档对比；offline contract 仍可在 CI 跑。

## 5. 验证

- 后端全量：`970 passed, 61 skipped`；
- 协作评测 offline + 15 场景模型评测通过；
- 前端 `npm run build` 通过。
