# Anvil v1.48.3 — 安全 finding 详情页报告式纸张重设计

> 版本：1.48.3（前端 UI 重设计；无后端/CLI 行为变更）

## 修复

- **“人工决策记录”黑底黑字**：`.finding-decision-record` 使用了深色 `--bg-soft`（`#1b1a23`），但没有显式设置文字颜色，标题继承纸面墨色 `#14131a`，对比度约 1.07:1；决策人/时间约 3:1。现改为中性纸面卡 + 状态色左竖条/图标，标题、决策人、时间和备注全部恢复纸面墨色。
- **草稿 callout**：同步去掉深色 `--bg-soft`，改为纸面提示；需重评使用浅琥珀提示。
- **原始 ISO 时间**：抽屉元信息、人工决策时间、底部外部提交时间、问题板卡片时间与导出结果时间全部格式化为 `YYYY-MM-DD HH:mm:ss` 本地时间。
- **纸面徽标低对比**：抽屉内状态、置信度、风险类型、外部编号补齐纸面配色；深色问题板卡片保持原来的深色徽标，外部编号使用亮绿色。

## 重设计

- **右侧抽屉**：恢复贴右、满高、无圆角，修复被 `.modal-overlay` 覆盖成居中卡片的问题；标题提升到约 18px，头部左对齐。
- **判定摘要**：宽屏 5 项一行，纸张卡使用暖灰描边；≤1200px 3 列、≤760px 2 列、≤520px 1 列。
- **人工决策记录**：移到判定摘要下方、问题定位之前；浅色纸面卡，显示决策类型、决策人、本地时间与备注；confirmed 红、false_positive 绿、changes_requested 琥珀，与顶部状态语义一致。
- **问题定位**：模块/函数/文件独立纸张卡，代码值使用等宽字体。
- **详细信息**：原来的分字段卡片合并为一张纸面文档，左标签右正文，行间虚线。
- **底部**：固定操作栏保留现有决策/提交按钮，窄屏自动换行。
