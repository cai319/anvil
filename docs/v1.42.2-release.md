# Anvil v1.42.2 — 问题板实时刷新与五色状态语义统一

> 发布日期：2026-11-10
> 版本：1.42.2

## 1. 问题板（Finding）变更实时刷新

此前问题创建、提交、确认/驳回、重评估等操作后，任务详情的问题板与详情抽屉不会
自动刷新，需要手动重载页面。

修复：

- 后端 `api/findings.py` 在以下操作后统一发布 `topic=task` 的 `kind=finding`
  事件：创建、更新、提交、确认、误报、要求修改、重新打开、删除、完成、
  重新打开问题板、外部提交、评审人变更。
- 前端 `TaskFindingBoard` / `FindingDrawer` 订阅任务事件；匹配当前任务时静默
  重新加载，避免整页闪烁。
- `request_changes`、`reopen_board`、`_writable_board` 会清空 `completed_at`，
  修复“要求修改后问题板仍显示已完成”的状态残留。
- `tests/api/test_issue_board_api.py` 增加事件发布与 `completed_at` 重置断言。

## 2. 五色状态语义统一

角色点灯、状态徽标、头像阴影、运行指示灯、工作流节点与问题板统一为五色：

| 颜色 | 含义 | 状态 |
|---|---|---|
| 绿 | 空闲 / 成功 | `idle` `done` `completed` `approved` `suspended` `ready` |
| 橙 | 正在处理 | `in_progress` `running` `projecting` `created` `switching` |
| 黄 | 等待人工介入 | `in_review` `submitted` `reviewing`、任务 `in_review`、HITL 门禁 |
| 红 | 排队 / 繁忙 / 失败 | `queued` `busy` `failed` `rejected` `unhealthy`、返工 |
| 灰 | 结束 / 关闭 / 中性未开始 | `closed` `abandoned` `skipped`（深灰）；`todo` `pending` `unknown` `unverified` `missing`（浅灰） |

行为修正：

- 角色进程存活或上下文仍保留时显示绿色“空闲”；只有进程不在且无上下文时
  才显示灰色“待办”，不再把存活角色误标成未开始。
- 任务/步骤/run 等待人工评审或确认时统一黄色。
- 步骤失败与返工统一红色；此前 rejected 为黄色、failed 为灰色。
- 任务终止/关闭为深灰，任务 `todo` 为中性浅灰，二者不再混用。
- 清理 `pages.css` 与 `components.css` 中重复的 status / status-light /
  run-live 定义，状态颜色只保留一份权威映射。
- 大厅任务卡头像、运行卡指示灯、AgentSessions 头部、RoleSessions 行、
  TaskDetail 角色 chip 的阴影/点灯颜色同步。
- 问题板移除蓝色返工态，改为红色；“分析进行中”由黄色改为橙色；
  HITL 门禁“等待人工”为黄色、“等待 AI”为橙色；派遣任务 `cancelled`
  修正为灰色。

## 3. 点灯与徽标的职责

- 点灯/头像阴影：表达实时运行态（空闲、处理中、繁忙、排队、切换、失败等），
  只有颜色，用于快速扫描。
- 状态徽标：表达该任务/切片对该角色的业务状态，带文字（待办、进行中、
  等待人工、返工、失败、完成、已终止等），并保留 claim/workflow 回退。
- 两者共享同一优先级：终止 → 完成 → 失败/返工 → 等待人工 → 等待重试 →
  切换上下文 → 忙碌/排队 → 空闲/待办。
