# Anvil v1.48.6 — finding 详情静默刷新

> 版本：1.48.6（前端修复；无后端/CLI 行为变更）

## 修复

- finding 详情弹窗每约 30 秒闪动并回到顶部：`useLiveRefresh` 的 SSE/30 秒兜底每次触发都会执行 `setFinding(null)`，导致标题变“加载中…”，徽标、正文、页脚卸载，滚动位置归零。
- 现在区分“初次/切换 finding”和“后台刷新”：
  - 只有 `taskId`/`findingId` 变化时才清空并显示加载态；
  - 30 秒轮询、finding SSE、SSE 重连、窗口焦点/可见性恢复全部静默刷新，不卸载正文、不重置滚动；
  - 仅在 `version`、`updated_at`、状态、外部提交、决策字段等真正变化时替换数据，未变化不重渲染；
  - 后台刷新失败保留当前内容，仅显示错误，下次成功清除。

## 验证

- 将 30 秒轮询在测试浏览器中缩短到 1.2 秒实测：
  - 修复前 5.2 秒内出现 4 次“加载中”、8 次正文卸载，滚动位置 298→0；
  - 修复后 0 次闪动、0 次正文卸载，滚动位置保持 298；期间仍发出 5 次详情请求。
- 注入 `confidence 80→81` 的 fixture：摘要静默更新，滚动位置保持 351，无加载态。
- 初次打开/切换 finding 仍显示加载；`npm run build` 通过。

## 升级

- 替换前端静态资源；版本文件统一为 `1.48.6`，`anvil --version` 输出 `1.48.6`。
- 无 API、数据库、调度或 CLI 命令变更。
