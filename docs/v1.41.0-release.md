# Anvil v1.41.0 — 问题板外部问题跟踪提交

> 发布日期：2026-11-05
> 版本：1.41.0

## 功能

- 任务问题板支持将 finding 提交到外部问题跟踪服务器的 `POST {server_url}/draft/bulkCreate`。
- 单条提交：finding 抽屉底部「提交到问题跟踪」。
- 批量提交：问题板「提交全部可提交问题」，默认提交 `submitted / confirmed / changes_requested`，排除 `draft / false_positive`。
- 提交仅接受 human；Agent 返回 403。
- 每次点击都会重新提交，本地不做跳过/去重；`source` 为 `anvil:<task_id>:<timestamp>`，外部服务端负责去重。
- 每条 finding 的 `description_md` 包含该问题的完整详情（任务/定位/风险/前置条件/推理链/攻击路径/PoC/修复建议/决策记录）。
- 工具页新增问题跟踪服务器配置：
  - 地址格式 `http://xxx.xxx.xxx.xxx/api`
  - 保存
  - 测试连接（空 list 探测，不创建真实草稿）
- 提交历史与最新外部 ID 落库：
  - `task_findings.external_id/external_source/external_submitted_at`
  - `task_finding_submissions`
- 任务删除级联清理提交历史；启动时清理孤儿记录。

## API

- `POST /api/v1/tasks/{tid}/findings/{fid}/external-submit`
- `POST /api/v1/tasks/{tid}/findings/external-submit`
- `GET  /api/v1/tooling/issue-tracker`
- `PUT  /api/v1/tooling/issue-tracker`
- `POST /api/v1/tooling/issue-tracker/test`

## 行为边界

- 未配置服务器时问题板/抽屉显示配置入口，按钮禁用。
- 外部提交不改变 finding/board 状态，不参与任务评审闸门。
- 外部服务器故障时保留失败历史并返回 502/504；已成功项不回滚。
- 重复提交按用户要求不拦截；外部服务端可用 source/内容字段自行去重。
